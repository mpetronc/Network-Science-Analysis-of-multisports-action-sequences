# Analysis of passing-hub centrality and entropy change

The primary sample includes 96 eligible team-seasons. Season-adjusted r=0.383, R2=14.6%, Holm-corrected pooled p=0.0007. A ten-percentage-point greater first20 hub involvement corresponds to approximately +0.026 normalized entropy change. Using later-present games as the reference gives r=0.368, R2=13.5%, corrected p=0.0027. Pooled inference clusters by franchise and adjusts for season. Corrected p values cover four pooled specifications, not the entire history of exploratory research.

Entropy increases in 90/96 (93.75%) eligible observations and falls in six. Median change is +0.0542. The regression asks whether the size of that change varies with prior hub involvement; the predominance of positive changes alone is not evidence for that slope. Leaving out each franchise in turn leaves r between 0.342 and 0.411. This suggests no single franchise is solely responsible, but is not independent validation. No individual-season main fit survives correction across the full 24 seasonal specification tests.

Largest eligible increases include Dallas 2022-23 (Luka Doncic, +0.164), Portland 2021-22 (Damian Lillard, +0.151), Charlotte 2024-25 (LaMelo Ball, +0.146). Largest decreases include Washington 2020-21 (Bradley Beal, -0.093), Minnesota 2020-21 (D'Angelo Russell, -0.081), New Orleans 2023-24 (Brandon Ingram, -0.050). These values are descriptive estimates, without team-specific uncertainty intervals. New York 2022-23 is an instructive exception: the hub involvement fraction is 46.5%, yet the entropy change is approximately -0.002.

A possible explanation for the positive slope is that passing becomes distributed among a larger set of receiver choices when an organizing hub is unavailable. The data do not establish this mechanism: removing a hub mechanically alters sender weights and available recipients; pooled roster changes and lineups, co-absences, opponents and seasonal drift can change conditional entropy too. Higher conditional entropy is not equivalent to equal player involvement or better performance. Weighted-degree centrality measures activity, not ability or causal importance. The association explains a modest part of variation (about 15%).

The latest split-role forecast has median absolute entropy error 0.0289 in the eligible sample, underestimates actual entropy in 64/96, and overestimates in 32/96. This indicates a tendency to forecast too little receiver diversity, but does not show it predicts individual connections well. Multiple very different networks can have the same entropy. These prediction errors use full-network levels; the centrality regression instead uses matched-pass-count observed entropy changes.
